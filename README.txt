SANJANA BIRTHDAY - GITHUB PAGES

1. Upload everything in this folder to your GitHub repository.
2. Keep index.html in the repository root.
3. Upload your photos into the images folder with these exact names:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
4. In GitHub: Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
5. Wait for GitHub Pages to publish your site.

The page is designed to work on iPhone/mobile browsers and uses relative image paths.
